Генератор плана работ

Веб-приложение на базе **FastAPI**, которое автоматизирует создание документов Microsoft Word (.docx) и электронных писем (.eml) для плановых работ. Оно рассчитывает временные интервалы, "Точку принятия решения" и подтягивает метаданные из конфигурации.

## Основные возможности
- Автоматический расчет времени начала/окончания для каждого этапа.
- Формирование "Плана работ" и "Плана отката".
- Расчет "Точки принятия решения" (Decision Point): старт сразу после работ, длительность минимум 30 минут с округлением.
- Динамические списки АС/ФП и ответственных лиц через `config.yaml`.
- **История генераций:** Сохраняет данные о ранее сгенерированных планах, позволяя их повторно скачать или загрузить данные в форму для редактирования.
- **Генерация писем (EML):** Автоматическое создание файла сообщения с заполненными адресатами и темой.
- **Типовые шаблоны:** Возможность выбора предзаполненных наборов работ из `templates.json`.

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ваш-аккаунт/rov-generator.git
   cd rov-generator
   ```

2. **Создайте виртуальное окружение и установите зависимости:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Запустите сервер:**
   ```bash
   python -m uvicorn app.main:app --reload
   ```
   Приложение будет доступно по адресу: `http://127.0.0.1:8000`

## Настройка шаблона Word (.docx)

Приложение использует библиотеку `docxtpl`. В файле `templates/template.docx` (и в HTML-шаблоне письма) доступны следующие переменные:

### Простые переменные
| Тег | Описание |
| :--- | :--- |
| `{{ RELEASE_NUMBER }}` | Номер релиза |
| `{{ START_DATE }}` | Дата начала (дд.мм.гг) |
| `{{ START_TIME }}` | Время начала (ЧЧ:ММ) |
| `{{ AS }}` / `{{ FP }}` | Выбранная АС и ФП |
| `{{ RESPONSIBLE }}` | Ответственный за проведение работ |
| `{{ CONTACTS }}` | Контактные данные ответственного |
| `{{ DESCRIPTION }}` | Описание проводимых работ |
| `{{ POSSIBLE_DOWNTIME }}` | Возможная недоступность |
| `{{ DP_START }}` / `{{ DP_END }}` | Начало и конец точки принятия решения |
| `{{ OWNER_NAME }}` | Владелец ФП (из конфига) |
| `{{ BLOCK_VAL }}` | Скрытая переменная блока |

### Таблицы (План работ и отката)

**Для Word (.docx):**

**План работ:**
1. В первой ячейке строки: `{% tr for item in WORK_TABLE %}`
2. Внутри ячеек: `{{ item.id }}`, `{{ item.work }}`, `{{ item.start_time }}`, `{{ item.end_time }}`, `{{ item.comment }}`.
3. В последней ячейке: `{% tr endfor %}`

**План отката:**
Используйте `{% tr for item in ROLLBACK_TABLE %}`. 
В этой таблице переменные `{{ item.start_time }}` и `{{ item.end_time }}` будут выводиться в формате **относительного времени** (например, `Y`, `Y + 00:15`), где **Y** — момент принятия решения об откате.
Переменная `{{ item.interval }}` выведет строку вида `Y - Y + 00:15`.

**Для Email (.html):**
Используйте стандартный синтаксис Jinja2 для формирования таблиц в `templates/email_template.html`.

## Генерация Email (.eml)

Приложение генерирует файл `.eml`, который можно открыть в Outlook или другом почтовом клиенте.
- **Шаблон:** `templates/email_template.html`.
- **Получатели:** Список берется из поля `email_to` в `config.yaml` для конкретной ФП.
- **Логотип:** Если в HTML-шаблоне используется `<img src="cid:logo">`, в письмо будет автоматически встроено изображение из `app/static/img/logo.jpg`.

## Шаблоны этапов (templates.json)

Вы можете заранее подготовить наборы этапов работ в файле `templates.json`. 
При выборе АС/ФП в интерфейсе приложение предложит только те шаблоны, которые соответствуют маппингу в `config.yaml`.

## Конфигурация (config.yaml)
Пример структуры файла в корне проекта:
```yaml
default_responsible: "Иванов И.И."
default_contacts: "+7-999-000-00-00"

fp_mapping:
  "АС Система1": ["ФП Модуль1", "ФП Модуль2"]

system_metadata:
  "АС Система1":
    "ФП Модуль1":
      approver_name: "Иванов И.И."
      approver_title: "Начальник отдела"
      owner_name: "Петров П.П."
      owner_contacts: "petrov@example.com"
      email_to: ["recipient@example.com"]
      email_recipients: ["cc-recipient@example.com"]
      block_val: "Блок IT"
```
